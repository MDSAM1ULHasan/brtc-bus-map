# BRTC Bus Routes & Timetables — Bangladesh

A free, static interactive map starter for BRTC route and timetable information.

## Current features

- Detailed zoomable street map powered by MapLibre GL JS and OpenFreeMap.
- Bengali/English map labels where the basemap data supplies them.
- Responsive desktop/mobile layout.
- Search for loaded route and stop feature properties.
- Clickable terminal markers and road-route popups.
- Imports custom GeoJSON FeatureCollections.
- Automatically generates a road-network driving path between paired origin/destination terminal features using the public OSRM demo service.

## Initial route dataset

The current pilot dataset is `data/brtc-routes.geojson`, for Dhaka–Faridpur. It contains published schedule details attributed to BRTC's passenger transport information page:
https://brtc.gov.bd/site/page/5001091c-e4a6-4949-a6bc-e70bae7bfd63/Citizen

The origin/destination pin coordinates are derived from public mapped/geotagged sources linked in the GeoJSON properties. Review the pins before using them.

**Important:** the road line is generated by OSRM's normal driving router. It is only a road-following approximation between terminals, not a verified BRTC bus trace or official GPS route. The timetable is copied from a published BRTC table and current operating status has not been independently reconfirmed. Verify schedules with BRTC before travelling.

## Adding more routes

Add a pair of Point features to `data/brtc-routes.geojson`, one with `properties.route_id` and `properties.stop_type = "origin"`, another with the same `route_id` and `properties.stop_type = "destination"`. Supply coordinates in GeoJSON order `[longitude, latitude]`. Useful properties include:

- `route_name`
- `stop_name` and `stop_name_en`
- `departure_first_time`, `departure_frequency`
- `arrival_first_time`, `arrival_frequency`
- `published_distance_km`
- `schedule_source`, `schedule_source_url`, `schedule_status`
- `coordinate_source`, `coordinate_source_url`

On page load, the app requests an OSRM road route between each endpoint pair and displays it as a dashed green line. It does not create intermediate stop markers unless those stop coordinates are added to the data. Public routing services have fair-use limitations and no uptime guarantee.

## Publish with GitHub Pages

GitHub Actions automatically deploys changes to the `main` branch through `.github/workflows/deploy-pages.yml`. If Pages settings need checking, open **Settings → Pages** in this repository.
